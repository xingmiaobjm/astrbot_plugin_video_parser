# 视频解析助手

一款为 AstrBot 设计的多平台视频/图片自动解析插件，支持抖音、B站、小红书、X(Twitter) 等平台链接的自动识别与解析。

## ✨ 功能特性

- **多平台支持**：自动识别并解析抖音、B站、小红书、X(Twitter) 平台的视频链接
- **自动解析**：检测到消息中的支持平台链接时自动解析并回复
- **视频下载**：解析后自动下载视频并作为文件发送到聊天中
- **引用回复**：发送消息时自动引用用户的原始消息
- **缓存机制**：缓存解析结果，减少重复请求，提高响应速度
- **WebUI 配置**：提供完整的设置页面，支持平台开关、参数调节、手动测试和统计查看

## 📦 安装

1. 将插件目录放置到 AstrBot 的 `plugins/` 目录下
2. 重启 AstrBot，插件将自动加载
3. 在 WebUI 中访问「视频解析助手」设置页面进行配置

## 🎯 支持平台

| 平台 | 支持链接格式 | 说明 |
|------|-------------|------|
| 抖音 | `v.douyin.com` / `douyin.com` | 需配置第三方解析 API |
| B站 | `bilibili.com` / `b23.tv` | 原生解析 |
| 小红书 | `xiaohongshu.com` / `xhslink.com` | 支持图文和视频 |
| X (Twitter) | `twitter.com` / `x.com` | 原生解析，建议配置 Cookie |

## ⚙️ 配置说明

### 通用设置

- **自动解析**：开启后自动检测消息中的链接并解析
- **发送视频文件**：下载视频后作为文件发送，关闭则仅发送文字信息
- **启用缓存**：缓存解析结果，减少重复请求

### 参数调节

- **最大视频大小 (MB)**：超过此大小的视频仅发送文字信息（默认 50MB）
- **请求超时 (秒)**：请求视频平台 API 的超时时间（默认 30 秒）
- **缓存过期时间 (分钟)**：解析结果缓存的有效时长（默认 30 分钟）

### Cookie 配置

部分平台反爬严格，配置 Cookie 可提高解析成功率：

- **X (Twitter) Cookie**：从浏览器开发者工具获取
- **小红书 Cookie**：获取 `a1`、`web_session` 等字段，从浏览器 Application → Cookies 获取

### 第三方解析 API

- **抖音解析 API**：抖音反爬严格，建议配置第三方解析 API。接口格式：GET 请求，返回 JSON 包含 `title`、`author`、`video_url` 字段，支持 `{url}` 占位符

## 📱 使用方式

### 自动解析

开启「自动解析」后，当群聊消息中包含支持平台的链接时，插件会自动解析并回复。

### 手动指令

```
/parse_video <链接>
/解析视频 <链接>
/parse <链接>
```

### 查看状态

```
/parse_status
/解析状态
```

## 📤 消息格式

解析成功后，消息包含以下内容：

1. **引用回复**：引用用户的原始消息
2. **文本信息**：视频标题 + 作者名称（不含链接）
3. **视频文件**：下载后的视频文件（若开启「发送视频文件」）

## 📊 统计看板

设置页面的「统计看板」标签页提供：

- 总解析次数、失败次数、成功率
- 各平台解析分布统计
- 缓存状态信息

## 🛠️ 开发

```bash
# 安装依赖
pip install -r requirements.txt

# 目录结构
.
├── _conf_schema.json     # 配置 Schema
├── main.py               # 插件主入口
├── metadata.yaml         # 插件元数据
├── requirements.txt      # Python 依赖
├── pages/               # WebUI 页面
│   ├── settings/        # 设置页面
│   └── stats/           # 统计页面
└── parsers/             # 平台解析器
    ├── __init__.py
    ├── base.py          # 解析器基类
    ├── bilibili.py      # B站解析器
    ├── douyin.py        # 抖音解析器
    ├── twitter.py       # X(Twitter) 解析器
    └── xiaohongshu.py   # 小红书解析器
```

## 📝 注意事项

1. 抖音平台反爬严格，建议配置第三方解析 API
2. 小红书和 X 平台建议配置 Cookie 以提高解析成功率
3. 视频下载受网络环境影响，超时时间可根据需要调整
4. 缓存机制可有效减少重复请求，但会占用一定内存
